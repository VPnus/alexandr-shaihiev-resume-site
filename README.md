# Resume Landing — Alexandr Shaihiev

Статичный лендинг-резюме: `index.html` + `css/style.css` + `js/script.js`. Без сборки, без бэкенда — можно открыть локально или закинуть на любой статичный хостинг.

## Как посмотреть локально

```bash
cd "Resume lending"
python3 -m http.server 8642
```

Открыть http://localhost:8642

## Домен и хостинг — рекомендация

Для одностраничника-резюме **не нужен свой сервер/VPS** — это лишние деньги и обслуживание (обновления ОС, SSL, аптайм — всё вручную). Оптимальный вариант:

1. **Хостинг — бесплатный статичный хостинг**: Cloudflare Pages, GitHub Pages или Netlify.
   - Просто загружаете эту папку — сайт публикуется за пару минут.
   - Бесплатный SSL (https), CDN, 99.9% аптайм из коробки.
2. **Домен — купить отдельно** (~10–15 $/год, напр. на Cloudflare Registrar, Namecheap, Reg.ru): что-то вроде `alexandrshaihiev.com` или `shaihiev.dev`.
   - Домен подключается к бесплатному хостингу за 10 минут (просто прописываете DNS-записи).
   - Без своего домена сайт будет жить на поддомене вида `yourname.pages.dev` — тоже рабочий вариант, если экономите.

Свой хостинг (VPS/выделенный сервер) имеет смысл, только если планируете что-то сложнее статичной страницы (бэкенд, база данных, много трафика) — для резюме это не тот случай.
